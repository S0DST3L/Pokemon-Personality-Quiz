# 🌸 Pokémon Personality Matcher (Gens 1–9)

An aesthetic, pastel webcore personality quiz that matches users to their exact Pokémon counterpart out of all **1,025 species** (Generation 1 through the *Scarlet & Violet: The Indigo Disk* expansion).

### Features
* **Full National Dex Coverage:** Evaluates all 1,025 base species (excluding temporary forms and Mega Evolutions).
* **20-Question In-Depth Engine:** Scores responses across multiple axes including typing, temperament, habitat, and battle role for maximum accuracy.
* **Retro Pastel Aesthetic:** Built with a nostalgic Windows XP / Webcore interface featuring custom floating pixel sprites and pastel tones.
* **100% Static & Client-Side:** Lightweight, responsive, and hosted directly on GitHub Pages.
